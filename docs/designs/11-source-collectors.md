# AIHOT 示范源与多渠道采集

本次接入固定参考 AIHOT `ddf1c19ef2302863748dce51e4fdcd60d4415fc0`。示范清单来自 `industry/sources.json`，保存在 `server/internal/sources/presets/aihot.json`，保留上游 MIT 许可文件。参考采集协议与配置含义，在 Go 中实现；不执行上游脚本。

## 可用范围

| 类型 | 支持内容 | 限制 |
| --- | --- | --- |
| RSS / Atom | 18 个示范源一键选择导入；现有 RSS 采集器 | 默认暂停，试抓后启用 |
| GitHub | 仓库资料、README、指标、试抓 | 沿用原适配器 |
| JSON | 公开 GET 接口；列表路径、候选字段路径、原文链接模板、正文、作者与日期映射 | 不执行脚本，不支持任意鉴权头、POST 或 JS 内嵌数据 |
| 网页 | 静态 HTML、CSS 条目/链接/标题/摘要/日期选择器、相对 URL | 不执行 JavaScript，不接 Jina 或浏览器渲染 |
| X | SocialData 当前一页搜索结果；稳定帖子身份 | 需要密钥、单次预占、每日预算和每条价格；不额外请求长文章、引用上下文或媒体 |
| 公众号 | 极致了文章列表、新文章正文、去重检查点 | 试抓只查列表；正式采集新文章会请求正文 |
| 外部推送 | 保持原有推送接口 | 不主动试抓 |

## 导入与首次收录

- 导入使用固定 source_key；已有相同示范标识或 RSS 地址则跳过，不覆盖名称、频率、启停等人工配置。整批导入、审计和幂等响应同事务提交。
- 导入后的信源均暂停、不允许全文展示；默认首次最多收录最近 8 条，可以在配置中调整为 1–100 条。
- 首次有意略过的历史资料记录内容哈希，后续轮询不会继续灌入同一批旧文；其中有实质变化的资料仍可重新进入。旧版本已建立检查点的信源不重新执行首次截断。
- 修改采集位置或解析配置可重置检查点；补齐默认参数、暂停/恢复或更改公众号显示昵称不应意外重置采集进度。

## 试抓边界

`POST /api/admin/sources/preview` 可使用未保存配置，调用同一适配器并展示最多 20 条标题、网址、原文日期与摘要。不调用 Accept、Publisher、Editorial，不创建 raw_items、source_runs、processing_runs 或 resources，不更新检查点。

暂停信源仍可手动试抓；试抓会访问外部网络。付费渠道会保存调用回执与预算记录，但不把试抓内容录入资料库。无法解析日期时保留未知，不用抓取时间填充原文日期。普通 HTML 不运行脚本，无法匹配时明确提示检查选择器或动态渲染。

## 付费回执决策

- SocialData 和极致了的密钥只从服务端环境变量读取。没有密钥或正数预算配置时，拒绝试抓与启用，界面标记“等待服务商配置”，不返回模拟结果。
- `provider_calls` 增加 preview_request_key 与 request_summary。恰好一种上下文有效：加工阶段、真实采集运行、或管理员绑定的试抓请求。无需为了付费预览伪造资料与采集任务。
- 请求上下文、用途决定幂等身份；配置与价格指纹不同则拒绝同键重放。成功结果与预算结算同事务保存，重试复用回执。
- 调用前原子预占每日预算。SocialData 按配置的每条价格计算；极致了采用 cost_money。网络错误、结果或费用不明时保留额度并停止自动重复发送；同一来源的后续采集也不能绕过未确认回执。
- 即使模型调用关闭，付费回执恢复扫描仍可运行。回退迁移时若已有付费预览回执则拒绝回退，避免破坏费用记录。
- 请求摘要只保存已验证的公开配置，回执过滤账户余额、密钥等供应商私有字段；不把供应商返回原样送入资料库。

## 安全与配置

沿用 DNS 解析后地址检查、连接地址绑定、超时、响应大小和重定向限制。JSON 和付费渠道只跟随同源重定向，防止认证信息或 POST 请求体被带到其他来源。内网地址仅在测试注入的客户端允许，生产配置不能开启此例外。

网页选择器由 cascadia 解析，JSON 路径支持点号和数字数组下标，非空结果全部映射失败会报错。管理接口保留会话和 CSRF；每个进程最多同时执行 3 个试抓。

配置项见 `.env.example`：

- X：SOCIALDATA_API_KEY、NEX_SOCIALDATA_DAILY_LIMIT、NEX_SOCIALDATA_MAX_REQUEST_COST、NEX_SOCIALDATA_PRICE_PER_POST，币种 USD。
- 公众号：DAJIALA_KEY、NEX_DAJIALA_DAILY_LIMIT、NEX_DAJIALA_MAX_REQUEST_COST，币种 CNY。
- 密钥也可使用 NEX_SOCIALDATA_API_KEY / NEX_DAJIALA_KEY 别名；更改配置后需同时重启 API 和 worker。预算默认 0，不自动开通付费调用。
